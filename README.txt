Sathyabama R2023 CSE (AI & ML) Marks & GPA Calculator (v3)

Open index.html in a browser. To install it as an offline app on Android, host the folder on an
HTTPS static host (for example GitHub Pages), open it in Chrome, then use menu > Install app /
Add to Home screen. This is a web app (PWA), not an APK.

Privacy: no backend, database, analytics, localStorage or remote API. Marks are held only in page
memory and disappear on refresh/close.

Assessment patterns (out of 100)
- Theory: (CAE1 + CAE2) to 40, assignment to 10, end semester exam /100 to 50.
- Theory + Practical: theory internal 50; (lab assessment /50 + practical exam /50) to 50.
- Theory with Project: theory internal 50; project report review 50.
- Practical: session-wise /30, model exam /50 to 20, end semester practical 50.
- Physics Lab and Chemistry Lab: 25 + 25, converted to 100.
- Project: reviews 50, viva-voce 50.
- Professional Training / internship: external review 100.
- Skill Enhancement: end semester exam 100.
- Mandatory Audit: pass/fail, no credits.

Pass: total at least 50 AND end semester exam at least 30% of its maximum.
GPA: passed courses only; RA is excluded.

Please confirm with your department
- Professional Training: the regulations show 100 external, the curriculum table shows 50 + 50.
  The app follows the regulations.
- Theory + Practical: the app applies the 30% minimum to the end semester practical alone.
- Rounding of totals such as 89.5 is not stated; the app does not round.

Elective and skill course names can be picked or typed in the app.
curriculum.json is a reference copy of the data built into index.html.
